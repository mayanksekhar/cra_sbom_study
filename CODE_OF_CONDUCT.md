# Code of conduct

This repository is a research project about the quality of SBOM and VEX data under the EU Cyber Resilience Act. Everyone who takes part, by opening an issue, sending a pull request or reviewing, is expected to follow these rules.

## What we expect

* Be respectful and assume good faith. Criticise results, methods and code, not people.
* Give evidence for a claim: a command, a version, a file or a hash that others can check.
* Accept corrections. A reproduced failure is a contribution, not an attack.
* Keep private data out of the project: no keys, tokens, personal addresses or other people's data.

## What is not acceptable

* Harassment, insults, discrimination or personal attacks of any kind.
* Publishing someone else's private information.
* Spam, or content that has nothing to do with the project.

## Reporting and enforcement

To report a conduct problem, send a private message to the maintainer through the contact options on the maintainer's GitHub profile (github.com/mayanksekhar). Security problems in this repository go through private vulnerability reporting, see SECURITY.md. The maintainer may edit or remove comments, lock threads, close pull requests and block users who break these rules.

This code applies to all spaces of this repository, including issues, pull requests and discussions.
