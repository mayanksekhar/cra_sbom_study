# Pilot findings (descriptive, 10 projects, not statistical evidence)

Tools: Syft 1.45.1, Trivy 0.69.3, cdxgen 12.9.0. Projects: 2 each for Go, Maven, npm, PyPI, Rust.
Scoring: purl normalized, root project and workspace members excluded, GitHub Actions components excluded.

## Verified

1. The definition of truth changes the ranking. For node_exporter at name plus version, F1 against declared, resolved and shipped (3 platforms) truth is: cdxgen 0.92, 0.75, 0.99; Syft 0.96, 0.87, 0.90; Trivy 1.00, 0.83, 0.93.
2. Lockfile dependence. Express without a lockfile: Syft 0 components, Trivy 0, cdxgen 368. With a lockfile, Syft and Trivy match the 64 shipped packages exactly.
3. Scope policy differs by tool. cdxgen includes dev dependencies (npm) and all Maven scopes (171 and 40 artifacts). Trivy matches runtime scope on Maven (105 of 106 and 2 of 2). Syft and Trivy drop npm dev dependencies.
4. Scope leakage from nested manifests. axios ships 26 packages from its root lockfile, but Syft and Trivy report about 205 from 6 lockfiles (docs site, tests). Same pattern in ripgrep (fuzz/Cargo.lock) and flask (examples/celery/requirements.txt).
5. Syft on Maven reads direct dependencies only (28 of 171 artifacts on petclinic) and gives no version for 25 of those 28.
6. Python with a lockfile: all three tools find 7 of 7 runtime packages in flask but report 98 (Syft), 78 (cdxgen) and 29 (Trivy) components in total. Without a lockfile (requests), Syft and Trivy find 0 of 4 runtime packages and cdxgen finds 4 of 4 plus 50 extras.
7. Syft adds GitHub Actions components (6 to 28 per project) to product SBOMs.
8. cdxgen resolves for the host platform only. Its 46 Go modules equal the linux amd64 binary, and the 47th module (lufia/iostat) appears only for other targets.
9. Syft and Trivy list the root project as a component with an empty version on Go.

## Method caveats

1. cdxgen agreement on Maven, npm and Rust is partly circular, because truth comes from the same package managers.
2. Express lockfile was generated by us (recorded in groundtruth/npm/express_lockfile.txt).
3. Truth for requests (no lockfile) depends on the resolution date. Use name level for it.
